# Refleksi
## 1. Kapan native lebih tepat dipilih daripada cross-platform?
Saat aplikasi butuh performa grafis maksimal, akses hardware spesifik yang belum didukung cross-platform, atau efisiensi memori ekstrem.
## 2. Bagaimana perubahan state berhubungan dengan widget tree dan UI deklaratif?
UI deklaratif memperbarui tampilan secara otomatis berdasarkan perubahan state, yang memicu rebuild pada bagian widget tree terkait.
## 3. Mengapa commit kecil dengan pesan jelas bermanfaat bagi pekerjaan tim dan portfolio?
Mempermudah code review dan debugging dalam tim, serta mencerminkan profesionalisme yang terstruktur untuk portfolio.
