# 1. Kapan native dipilih
   Sangat tepat untuk aplikasi yang membutuhkan performa grafis tinggi (seperti game berat), akses mendalam ke fitur hardware spesifik yang belum didukung cross-platform, atau saat Anda perlu menekan ukuran memori seminimal mungkin.

# 2. Hubungan state dan UI
   Dalam UI deklaratif, tampilan layar adalah cerminan langsung dari state. Saat state berubah, sistem otomatis membangun ulang (rebuild) bagian widget tree yang terdampak dan hanya memperbarui elemen visual yang berubah.

# 3. Manfaat commit kecil
   Memudahkan tim melakukan code review dan melacak sumber bug tanpa merusak kode lain. Untuk portfolio, rekam jejak ini membuktikan kepada rekruter bahwa alur kerja Anda sangat rapi, terstruktur, dan profesional.
